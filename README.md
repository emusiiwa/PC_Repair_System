# PC_Repair_System
PC Repair System project - 2022 school project for Information Systems 3 module

#Technologies used
HTML CSS JavaSCript PHP MySQL

#Description
PC Repair System is a year-long school project made by 4 students. A system designed for employees to add PCs as they come for repairs, assign a technician to the job, monitor progress, and communicate with the owner/customer. Technicians can manage repair parts inventory, update job status, and communicate with customers. Key Features: user authentication, browsing of available inventory, updating job status, and direct communication with the PC owner.
